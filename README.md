# 轻译 LightTrans

自用 Chrome 翻译插件（Manifest V3，纯原生 JS，无需构建）。连接任意 OpenAI 兼容接口，自定义 Base URL / API Key / 模型，不绑定任何服务商。

## 功能

- **划词翻译**：选中网页文本 → 点击「译」按钮 → 流式输出翻译卡片（可拖动、可复制、Esc 关闭）；也可右键菜单「轻译：翻译所选文本」
- **整页双语翻译**：点击工具栏图标 →「翻译此页」，译文插入原文下方、复制原文排版；再点一次移除。批量 + 并发 + 缓存，重复翻译不再请求
- **弹窗文本翻译**：点击工具栏图标，输入任意文本，Enter 翻译，支持自动 / 指定方向（中英互译）
- **深色模式**：所有界面跟随系统自动切换

## 安装

1. 打开 `chrome://extensions`
2. 右上角开启「开发者模式」
3. 点击「加载已解压的扩展程序」，选择本目录（`light-trans/`）

## 配置

首次使用进入设置页（弹窗右上角齿轮）：

1. 选择服务商预设（DeepSeek / OpenAI / Kimi / 通义千问 / 火山方舟 / OpenRouter），或手动填 Base URL
   - Base URL 填到根路径或 `/v1` 即可，自动补全 `/chat/completions`
2. 填 API Key（只保存在本机 `chrome.storage.local`，仅 background 读取，不进入页面上下文）
3. 填模型名，点「测试连接」确认可用，保存

高级选项：温度、整页翻译的每批段落数 / 并发数、附加翻译指令（如“专有名词保留英文”）。

## 目录结构

```
manifest.json        MV3 清单
background.js        service worker：所有网络请求、流式/批量翻译引擎、缓存、右键菜单
content.js           划词翻译卡片（Shadow DOM）+ 整页切分/双语渲染
popup/               工具栏弹窗
options/             设置页
icons/               图标（gen_icons.py 可重新生成）
```

## 实现要点

- 流式输出：SSE 逐 token 渲染，划词/弹窗翻译首字即显
- 整页翻译批量协议：多段落编号后单次请求返回 JSON 映射，解析失败自动逐段兜底重试
- 翻译缓存：`hash(模型+目标语言+原文)` 为键存本地，上限 4000 条自动淘汰
- 修改代码后在 `chrome://extensions` 点扩展的刷新按钮，已打开的页面需刷新后内容脚本才会更新
